🎯 Gerador de Tabuada

Um projeto simples em HTML, CSS e JavaScript que permite gerar a tabuada de qualquer número até um limite escolhido. Ideal para estudo e prática de JavaScript básico.

🚀 Funcionalidades

Escolher o número da tabuada.

Definir até qual número multiplicar.

Mostrar o resultado de forma organizada na tela.

Validação simples para garantir que os campos sejam preenchidos corretamente.

🎮 Como Usar

Clone este repositório ou baixe os arquivos.

git clone https://github.com/seu-usuario/seu-repositorio.git


Abra o arquivo index.html em qualquer navegador.

Digite o número da tabuada e o limite desejado.

Clique em Gerar e veja o resultado aparecer abaixo do formulário.
